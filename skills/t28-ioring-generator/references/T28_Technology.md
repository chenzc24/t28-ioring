# T28 geometry and rule sources

Use the technology file for the active library’s database units, manufacturing grid, layer-purpose pairs and via definitions. Retain the resolution required by that grid through placement and export. Check the actual metal stack and stream-out map, including the upper-metal and pad layers used by this release.

Use the process DRM and matching Calibre deck for layer-specific width, spacing, area, enclosure and ESD routing checks. Device selection, bonding, abutment and chip integration are described in `enrichment_rules_T28.md`. Confirm the installed IO and CUP library release notes before selecting the physical pad master.
